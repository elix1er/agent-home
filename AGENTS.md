# Agent home

Keep this repo useful, personal, and light.

- Check what already exists before adding anything.
- Read `identity.md`, `goal.md`, and `inbox.md` before choosing work.
- Keep one clear current goal; move completed work into `archive/`.
- Save only reusable skills, automation prompts, and durable context.
- Never commit secrets, private exports, caches, or machine-local state.
- Prefer short plain files over frameworks and dependencies.
- Use a branch and pull request; do not push directly to `main`.
- Automations may suggest changes, but must not auto-merge, deploy, message people, rotate credentials, or delete data.
- If there is nothing genuinely useful to improve, say `no change`.
