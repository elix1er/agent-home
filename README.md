# agent-home

An early home for one persistent agent: who it is, what it is trying to do, what is next, and what it has learned.

- [`identity.md`](identity.md) — personality, role, and boundaries
- [`goal.md`](goal.md) — the current goal
- [`inbox.md`](inbox.md) — possible next work
- `archive/` — completed work and useful history
- `skills/` — capabilities worth reusing
- `automations/` — recurring prompts

This is V0. It may become a template, or it may become the first real agent living here. The direction is intentionally open.

A weekly GitHub Action opens one review reminder. The matching prompt lives in [`automations/weekly-review.md`](automations/weekly-review.md) and can be used by any agent or local automation.
